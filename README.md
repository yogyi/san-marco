# San Marco — Premium Bedding & Comforters

Luxury e-commerce storefront for **San Marco**, featuring the Festive Comfort Collection of Made-in-India comforters and bedsheet sets.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Zustand cart (persisted)
- Framer Motion for subtle luxury motion

## Run locally

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:43127](http://127.0.0.1:43127).

## What’s included

- Home, shop (filters), product detail with size variants
- Cart drawer + 3-step luxury checkout (shipping → payment → review)
- Festive collection, gifting, about, contact, shipping pages
- Product imagery extracted from the brand PDF; specs informed by the product sheet
- Demo checkout (no real payment gateway) with order confirmation
